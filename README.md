# diplomarbeit-papo
Diplomarbeit PaPo - Entwicklung und Dokumentation eines Partnerportals

Web-basiertes Partnerportal: Company -> Partner -> Endkunde. Partner-driven ordering MVP.

## Struktur
- `backend/` - Quarkus (Java) API, Hibernate ORM Panache, PostgreSQL, Keycloak OIDC
- `frontend/` - HTML/CSS + native Web Components (kein Framework)
- `docs/` - Setup-Guide, Datenmodell, UI/UX-Doku
- `Specification/` - FSD, Implementation Plan, Phase-2 Backlog
- `Documentation/` - Besprechungsprotokolle
- `openspec/` - Spec-driven change `build-partnerportal-mvp` (proposal, design, specs, tasks)

## Setup
Siehe `docs/SETUP.md` (Container, Backend, Frontend, Demo-Logins, Tests). Konventionen: `docs/CONVENTIONS.md`.
